# E-commerce Website

A modern e-commerce website built with HTML, CSS, and JavaScript. This project implements a responsive design with features like product filtering, search functionality, and shopping cart management.

## Features

- Responsive design that works on desktop and mobile devices
- Product category filtering
- Search functionality
- Shopping cart with add/remove items
- Product grid display
- Notification system for cart updates
- Modern UI with smooth animations

## Setup Instructions

1. Clone this repository to your local machine
2. Make sure you have all the required images in the correct directories
3. Open `index.html` in your web browser

## Required Images

You'll need to add the following images to make the website work properly:

- `images/logo.png` - Your website logo
- `images/hero-bg.jpg` - Hero section background image
- `images/products/ssd.jpg` - SSD product image
- `images/products/laptop.jpg` - Laptop product image
- `images/products/monitor.jpg` - Monitor product image
- `images/products/printer.jpg` - Printer product image
